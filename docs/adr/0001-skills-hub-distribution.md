# ADR-0001: Skills Hub 배포 모델

- 상태: Accepted
- 날짜: 2026-03-16

## 문맥
프로젝트 시작 시 필요한 스킬만 선택 설치하고, 도메인 독립 허브를 공개 저장소로 운영해야 한다.

## 결정
`Tag 기반 Hub + 선택 설치` 모델을 채택한다.

## 근거
- 프로젝트별 불필요 파일 유입 최소화
- 공개 저장소 운영 시 변경 영향 범위 제어
- 설치 경험 단순화

## 결과
- `manifests/skills.json` 중심 인덱스 운영
- 스킬은 `scripts/install-skill.sh`로 선택 설치
